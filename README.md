# 📚 WisdomShelf

WisdomShelf is a simple book-summary website that helps users learn the most valuable knowledge from great books without having to read every book. It provides easy-to-read summaries of popular books across topics like self-improvement, productivity, mindset, finance, and personal growth.

## ✨ Features
- 📖 Collection of book summaries
- 🧠 Key ideas and lessons from each book
- 🔍 Simple and user-friendly interface
- 📱 Responsive design
- 🌐 Individual pages for each book
- ⚡ Fast and lightweight static website

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🎯 Purpose
The goal of WisdomShelf is to make learning from books easier, faster, and more accessible by presenting the most useful ideas and lessons in a simple format.
